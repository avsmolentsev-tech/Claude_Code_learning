- **Название:** «Ставим ИИ-агента Claude Code на Windows за 10 минут — для НЕпрограммистов» (69 знаков)
- **Структура:**
  - 0:00–1:00 — интро: кто я (предприниматель, не айтишник), что будет в видео, результат в конце
  - 1:00–2:30 — демо-приманка: готовый агент делает реестр из папки договоров (снято заранее)
  - 2:30–4:00 — что понадобится: аккаунт с подпиской (отсылка к отдельному видео про регистрацию из РФ)
  - 4:00–7:00 — установка: открываем PowerShell, одна команда `irm https://claude.ai/install.ps1 | iex`, проверка `claude --version`, запуск и авторизация
  - 7:00–9:00 — первая задача: «создай файл со списком дел» — показать запрос разрешения крупно
  - 9:00–10:30 — бонус: ставим VS Code + расширение, показываем дифф («видно каждое изменение»)
  - 10:30–11:00 — итог + анонс следующего видео (первые бизнес-задачи) + призыв подписаться
- **Что показать на экране:**
  - PowerShell крупным шрифтом (увеличить заранее до 20pt!)
  - Момент запроса разрешения агентом — стоп-кадр со стрелкой
  - Дифф в VS Code: красное/зелёное — «контроль у тебя»
  - Типичная ошибка вживую: «claude не распознан» → закрыли-открыли PowerShell → работает (не вырезать!)
- **Заметка:** ошибки в записи не вырезать — «честные грабли» и есть позиционирование канала.
