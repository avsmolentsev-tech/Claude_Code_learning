Подключаем Google Drive и Яндекс.Диск к агенту

Урок М6-01 показывает, как агент работает с уже подключённым диском. Здесь — как это подключение сделать с нуля, по шагам: официальный коннектор для Google Drive и проверенный способ для Яндекс.Диска, у которого официального коннектора нет.

Часть 1. Google Drive (официальный коннектор)

Сначала — важное разъяснение про почту

Аккаунт Claude и аккаунт Google — это два разных аккаунта, и они не обязаны совпадать:

  • Аккаунт Claude может быть зарегистрирован на любую почту — mail.ru, yandex.ru, корпоративную. Это не мешает подключить Google Drive.
  • При подключении коннектора Claude отдельно попросит войти в Google — и вот тут нужен именно Google-аккаунт.

Если Google-аккаунта нет вовсе: его можно создать на любую существующую почту — Gmail заводить не обязательно. На странице регистрации Google выбери «Использовать существующий адрес электронной почты» и укажи свою почту (хоть @mail.ru). Подводный камень для РФ: Google может запросить подтверждение по SMS, а на российские номера +7 SMS часто не приходят — те же обходные пути, что мы разбирали в М0-02 для регистрации Claude (номер друга за границей, виртуальный номер), работают и здесь.

Шаги подключения (claude.ai и приложение Claude)

  1. Открой claude.ai (или настольное приложение Claude) и войди в свой аккаунт.
  2. Слева внизу нажми на имя профиля → Настройки (Settings).
  3. Найди раздел Коннекторы (Connectors).
  4. В списке найди Google Drive и нажми Подключить (Connect).
  5. Откроется окно входа Google: выбери Google-аккаунт (или войди в него) и нажми Разрешить — Claude запросит доступ на чтение файлов Drive.
  6. Готово. В любом чате спроси: «Покажи последние файлы в моём Google Drive» — агент их реально увидит.

Альтернативный путь без настроек — прямо из чата: нажми «+» в поле ввода → Добавить из Google Drive → найди документ поиском или вставь ссылку. Так подключается доступ к конкретному файлу, а не ко всему диску.

Это же подключение работает и в Claude Code

Коннектор привязывается к аккаунту Claude, а не к конкретному приложению: подключил один раз в веб-интерфейсе — инструменты Google Drive (search_files, read_file_content, create_file и другие) доступны и в Claude Code под тем же аккаунтом. Именно так построен практикум М6-01: весь урок сделан из Claude Code через коннектор, подключённый в claude.ai.

Что коннектор умеет и не умеет

Умеет: искать по названию и по тексту внутри документов, читать содержимое, создавать новые файлы. Не умеет: редактировать, переименовывать и перемещать уже существующие файлы; картинки внутри документов не обрабатываются — только текст.

Часть 2. Яндекс.Диск (официального коннектора нет — подключаем сами)

У Anthropic нет готового коннектора для Яндекс.Диска. Но у Яндекс.Диска есть открытый REST API, и подключить его к Claude Code можно за ~10 минут. Понадобится OAuth-токен — «ключ», который ты выдаёшь сам себе в кабинете Яндекса.

Шаг 1. Получи OAuth-токен Яндекса (~5 минут, один раз)

  1. Зайди на oauth.yandex.ru/client/new (войди в свой Яндекс-аккаунт, если попросит).
  2. Заполни форму создания приложения:
    • Название — любое, например «Мой ИИ-агент» (его увидишь только ты).
    • Платформы — отметь «Веб-сервисы».
    • Redirect URI — нажми ссылку «Подставить URL для отладки».
  3. В разделе Доступ к данным найди группу Яндекс.Диск REST API и отметь:
    • cloud_api:disk.info — информация о диске;
    • cloud_api:disk.read — чтение файлов;
    • cloud_api:disk.write — запись файлов (если хочешь, чтобы агент мог создавать и менять файлы; для «только читать» — не отмечай).
  4. Нажми Создать приложение. На странице приложения скопируй ClientID.
  5. Открой в браузере адрес (подставь свой ClientID): 
    https://oauth.yandex.ru/authorize?response_type=token&client_id=<ClientID>
  6. Яндекс спросит разрешение — подтверди. На следующей странице появится токен (длинная строка). Скопируй его.

Токен действует год. Относись к нему как к паролю от диска: кто знает токен — тот имеет доступ ко всем файлам. Не вставляй его в документы, не отправляй в мессенджеры, не сохраняй в общие папки.

Сохрани токен в файл, доступный только тебе (команда для терминала):

echo "твой_токен" > ~/.yandex_disk_token
chmod 600 ~/.yandex_disk_token

Шаг 2. Подключи MCP-сервер к Claude Code (~2 минуты)

Для Яндекс.Диска есть готовый MCP-сервер сообщества — yandex-disk-mcp. Мы проверили его перед тем, как писать эту инструкцию: запускается, отдаёт 10 инструментов — список файлов, метаданные, создание папок, загрузка и скачивание, копирование, перемещение, удаление. Понадобится установленный Node.js — если ставил Claude Code по уроку М0-03, он уже есть.

Одна команда в терминале:

claude mcp add yandex-disk \
  --env YANDEX_DISK_TOKEN="$(cat ~/.yandex_disk_token)" \
  -- npx -y yandex-disk-mcp

Что она делает: регистрирует в Claude Code MCP-сервер с именем yandex-disk, который при каждом запуске подтягивается через npx и получает твой токен из файла.

Шаг 3. Проверь подключение

  1. Перезапусти Claude Code (закрой и открой заново).
  2. Набери /mcp — в списке должен появиться yandex-disk.
  3. Спроси агента: «Сколько места занято на моём Яндекс.Диске?» или «Покажи файлы в корне Яндекс.Диска».

Правило из урока М6-01 действует и здесь: проверяй содержимым, а не «оно вроде подключилось». Пусть агент покажет реальный список твоих файлов — если названия совпадают с тем, что видишь на disk.yandex.ru, подключение работает.

Запасной путь: без MCP-сервера, напрямую через API

Если MCP-сервер по какой-то причине не заводится, Claude Code может работать с Яндекс.Диском и без него — обычными запросами к REST API. Токен тот же. Скажи агенту:

Работай с моим Яндекс.Диском через REST API (cloud-api.yandex.net), токен лежит в файле ~/.yandex_disk_token. Покажи список файлов в корне.

Агент сам составит запросы вида:

curl -H "Authorization: OAuth $(cat ~/.yandex_disk_token)" \
  "https://cloud-api.yandex.net/v1/disk/resources?path=/"

Это тот же API, которым пользуется MCP-сервер, — просто без обёртки. Для разовых задач такой путь даже проще; MCP-сервер удобнее, когда работа с диском постоянная.

Часть 3. Гигиена после подключения

  • Токен и коннектор — ключи от всего диска. Прежде чем подключать, вспомни, что там лежит: клиентские договоры, чужие ТЗ, персональные данные. Агент получит доступ ко всему, а не только к «рабочей» папке.
  • «Агент видит» и «агент публикует» — разные разрешения. То, что агент может прочитать файл, не значит, что содержимое можно вставлять в посты, отчёты и публичные страницы (реальный пример — в «Заметках из практики» урока М6-01).
  • Отозвать доступ можно в любой момент: Google — myaccount.google.com/connections (найти Claude → удалить доступ); Яндекс — id.yandex.ru → «Безопасность» → «Приложения и сайты» (или удалить приложение на oauth.yandex.ru). Если токен «засветился» — отзывай сразу, новый выдаётся за 5 минут.
  • 152-ФЗ: если на диске персональные данные клиентов-физлиц, подключение внешнего ИИ к такому диску — та самая «передача третьему лицу», о которой подробно поговорим в уроке М6-03. Короткое правило до тех пор: работай через агента с обезличенными копиями (инструмент из М5-02), а не с оригиналами.
