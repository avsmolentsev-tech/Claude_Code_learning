Как зайти в Codex

Codex — агент от OpenAI, который живёт в терминале и делает работу на твоём компьютере, как Claude Code. Здесь — как получить к нему доступ из России: регистрация, подписка, установка и вход. Курс построен на Claude; Codex нужен как второй агент — запасной, когда упёрся в лимиты, и как второе мнение, когда первый агент застрял.

Зачем предпринимателю второй агент

Честно: если ты только начинаешь, второй агент тебе не нужен — доведи до результата один. Codex имеет смысл в трёх случаях:

  • Кончились лимиты. Работа посреди задачи упёрлась в потолок подписки, а доделать надо сегодня — переключаешься на второго агента и продолжаешь.
  • Нужно второе мнение. Агент третий раз чинит одно и то же и ходит по кругу — свежий взгляд другой модели часто ломает тупик за один заход.
  • У тебя уже есть подписка ChatGPT. Тогда Codex включён в неё, и заводить его — вопрос двадцати минут.

Заменять Claude на Codex посреди курса не надо: все уроки, скиллы и файлы CLAUDE.md написаны под Claude. Codex — рядом, а не вместо.

Что понадобится

Барьеры те же четыре, что и при регистрации Claude в уроке М0-02: VPN, нероссийская почта, иностранный номер для SMS и зарубежная карта. Хорошая новость: если ты прошёл М0-02, три из четырёх у тебя уже есть — VPN стоит, Gmail заведён, способ оплаты выбран. Докупить придётся только новый одноразовый номер.

Шаг 1. Включи VPN

OpenAI не работает из России: ни регистрация, ни оплата, ни сам вход в Codex. VPN нужен постоянно — не только при регистрации, но и каждый раз, когда запускаешь агента. Настройка и проверка — в уроке М0-02, шаг 1 (AmneziaWG, проверка на 2ip.ru).

Практическое следствие, о котором забывают: вход в Codex устроен через браузер, а сам браузер и терминал должны в этот момент видеть интернет через один и тот же VPN. Половина «зависших логинов» — это отвалившийся туннель.

Шаг 2. Заведи аккаунт ChatGPT

  1. С включённым VPN открой chatgpt.com → Sign up. Почта — тот же Gmail, что использовал для Claude (заводить отдельный не нужно).
  2. Когда попросят телефон — купи одноразовый номер на 5sim.net: в поиске услуг введи OpenAI или ChatGPT, страна — та же, что у твоего VPN-сервера (по умолчанию в курсе — Латвия).
  3. Вставь номер полностью, с кодом страны, дождись SMS на 5sim.net (10–30 секунд), введи код.

Если SMS не приходит за минуту — жми «Отменить» (деньги вернутся на баланс) и бери номер другой европейской страны. Две-три попытки — нормально, номера «выгорают».

Шаг 3. Оформи подписку

На бесплатном плане Codex не работает — это первое, обо что все спотыкаются. Нужен один из платных: Plus, Pro, Business, Edu или Enterprise.

  • Plus — $20/мес — рабочий минимум и разумный выбор для курса.
  • Pro — заметно дороже, имеет смысл только при ежедневной интенсивной работе агента.
  • Business — командный тариф, от двух рабочих мест.

Цены и состав тарифов OpenAI меняет часто — актуальные смотри на openai.com/chatgpt/pricing. Данные выше — на август 2026.

Российские карты не принимаются. Способы оплаты ровно те же, что уже разобраны в уроке М0-02, шаг 4 (виртуальные карты через ArpoZan, «Плати по Миру», MIG Pay, WantToPay или карта иностранного банка) — заново разбираться не придётся, повтори тот же путь. VPN при оплате должен быть включён.

Шаг 4. Установи Codex на компьютер

Одна команда. Открой терминал (Windows — PowerShell, macOS — Terminal) и вставь:

Windows:

powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"

macOS и Linux:

curl -fsSL https://chatgpt.com/codex/install.sh | sh

Эта же команда потом обновляет Codex до свежей версии — запускай её раз в пару недель.

Альтернативные способы, если привычнее: npm install -g @openai/codex (нужен Node.js — он уже стоит, если ставил Claude Code по уроку М0-03) или brew install --cask codex на Mac.

⚠️ Главная ловушка установки. В npm есть пакет с коротким именем codex — он не имеет отношения к OpenAI. Устанавливается без единой ошибки, а потом просто ничего не делает, и ты полчаса ищешь причину. Нужен именно @openai/codex, со слэшем и префиксом.

Про Windows и WSL. WSL (линукс внутри винды) для Codex не нужен: нативная установка в PowerShell работает, и агент использует встроенную песочницу Windows — блокирует запись за пределами рабочей папки и выход в сеть без твоего разрешения. WSL пригодится, только если сам проект завязан на линуксовые инструменты. Отдельная грабля: в служебной документации репозитория до сих пор висит устаревшая строка «Windows 11 via WSL2» — ориентируйся на официальный установщик выше, а не на неё.

Шаг 5. Войди в аккаунт

  1. Перезапусти терминал (иначе система не увидит новую команду).
  2. Перейди в папку, где лежат твои рабочие файлы, и набери codex.
  3. В появившемся меню выбери Sign in with ChatGPT.
  4. Откроется браузер с окном входа OpenAI. Войди в свой аккаунт и подтверди доступ.
  5. Вернись в терминал — вход завершится сам, ключи сохранятся на компьютере. Больше логиниться не придётся.

Как это устроено внутри (пригодится, когда что-то пойдёт не так): Codex поднимает на твоём компьютере временный локальный сервер на порту 1455 и ждёт, пока браузер вернёт ему подтверждение. Отсюда два типичных сбоя: браузер ушёл в интернет мимо VPN, либо порт 1455 занят другой программой.

Полезные команды на будущее:

codex login          # войти заново
codex login status   # проверить, под каким аккаунтом работаю
codex logout         # выйти (например, перед передачей компьютера)

Если браузера нет — работаешь на удалённом сервере или по SSH: запусти codex login --device-auth (режим в бете) — Codex покажет код, который вводишь в браузере на любом другом устройстве. Второй путь — пробросить порт: ssh -L 1455:localhost:1455 …

Вход по API-ключу — отдельный способ для разработчиков: оплата не подпиской, а по факту израсходованных токенов. Для курса он не нужен и почти всегда дороже.

Шаг 6. Проверь, что всё работает

  1. codex login status — должен показать твой аккаунт и план.
  2. Запусти codex в папке с рабочими файлами и попроси обычными словами: «Расскажи, что лежит в этой папке».
  3. Внутри Codex работают служебные команды: /status — что сейчас настроено, /model — сменить модель, /permissions — что агенту разрешено, /review — проверить сделанные изменения.

Правило то же, что и во всём курсе: проверяй содержимым, а не ощущением «вроде запустилось». Пусть агент назовёт реальные имена твоих файлов — совпало с тем, что видишь в проводнике, значит доступ настоящий.

Где ещё живёт Codex

Терминал — не единственный вход. Аккаунт один и тот же, подписка одна:

  • Расширение для редактора — VS Code, Cursor, Windsurf: developers.openai.com/codex/ide. Ставится как обычное расширение; если работаешь в VS Code по уроку М0-06 — это самый привычный вариант.
  • Десктоп-приложение — команда codex app открывает оконный интерфейс вместо терминала. Аналог вкладки Code в приложении Claude из урока М0-05.
  • Codex Web — облачный агент на chatgpt.com/codex: работает на серверах OpenAI, а не на твоём компьютере. Твоих локальных файлов он не видит.

Чем отличается от Claude Code

Логика работы одинаковая: ставишь задачу обычным языком, агент читает файлы, делает работу, спрашивает разрешения на опасные действия. Отличия, которые заметишь сразу:

  • Файл настроек называется AGENTS.md, а не CLAUDE.md. Смысл тот же — постоянные инструкции агенту про твой бизнес и твои правила (урок М0-07). Внутри Codex его создаёт команда /init.
  • Своя система разрешений и песочницы — настраивается через /permissions. Правила гигиены из урока М0-04 действуют без изменений: не раздавай доступ «на всё сразу», читай, что агент собирается сделать.

Какой агент «лучше» — вопрос без общего ответа: они меняются местами от версии к версии. Практический подход — держать оба и сравнивать на своих задачах.

Чек-лист

  • VPN включён, 2ip.ru показывает не-российский IP
  • Аккаунт ChatGPT создан, вход работает
  • Подписка активна — на бесплатном плане Codex не запустится
  • Установлен официальный пакет (@openai/codex, не короткий codex)
  • codex login status показывает мой аккаунт
  • Codex запущен в рабочей папке и назвал реальные файлы
  • Записал, каким способом оплачиваю, и поставил напоминание о продлении

Гигиена и данные

  • Файл ~/.codex/auth.json — это пароль. В нём лежат ключи доступа к твоему аккаунту. Не копируй его в общие папки, не отправляй в мессенджеры, не клади в облако. Передаёшь или продаёшь компьютер — сначала codex logout.
  • OpenAI — такой же иностранный сервис, как Anthropic. Все правила из урока М6-03 про 152-ФЗ действуют один в один: персональные данные клиентов-физлиц не отправляются во внешние модели, работаем с обезличенными копиями (инструмент из М5-02).
  • Два агента — две подписки и два счёта. Заводи Codex, когда есть понятная причина из списка в начале страницы, а не «на всякий случай».
