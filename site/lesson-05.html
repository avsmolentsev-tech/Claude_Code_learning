Клод на компьютере: десктоп-приложение и вкладка Code

Факты сверены с официальной документацией code.claude.com/docs и claude.com/download 23.07.2026. Приложение обновляется часто — при прохождении ориентируйся на смысл, не на точное расположение кнопок.

Что получишь

Обычную программу на компьютере — иконка в Пуске/Launchpad, окно, вкладки сверху. Внутри — тот же самый агент, что в уроке 03 работал в чёрном окне терминала, только в привычном виде программы, без единой команды.

Кому и зачем

После урока 03 агент уже работает — но живёт в терминале, а терминал многих пугает: чёрный экран, непонятные команды, страх что-то сломать. Следующий урок про VS Code даст самый мощный рабочий вид агента (файлы, дифф, всё в одном окне), но это тоже отдельная программа со своей логикой, которую нужно осваивать.

Между ними есть третий, самый простой путь — обычное десктоп-приложение Claude. Ставится и выглядит как любая программа (Word, Skype), внутри — тот же агент, что и в терминале, с доступом к твоим файлам. Если тебе не хочется трогать терминал вообще — это приложение может стать твоим основным рабочим местом, а VS Code из следующего урока пробуй уже как апгрейд, когда освоишься.

Шаги

Шаг 1. Скачай и установи приложение

  1. Открой claude.ai/download в браузере.
  2. Выбери свою систему: macOS (универсальная сборка, подходит и Intel, и Apple Silicon) или Windows (x64; для ARM-процессоров — отдельная сборка ARM64, ссылка на той же странице). Linux пока в бете.
  3. Запусти установщик, соглашайся с настройками по умолчанию.
  4. Запусти Claude — на Mac из папки «Программы», на Windows из меню Пуск.
  5. Войди тем же аккаунтом claude.ai, что регистрировал в уроке 02.

Шаг 2. Найди вкладку Code

В верхней части окна — три вкладки:

  • Chat — обычная переписка, без доступа к твоим файлам. По сути то же самое, что сайт claude.ai в браузере.
  • Cowork — агент работает в фоне, в отдельной изолированной среде, независимо от того, чем ты занят. Тема отдельного урока позже в курсе, сейчас не трогаем.
  • Code — вот она нам и нужна: даёт доступ к твоим локальным файлам и работает на том же движке, что терминальная команда claude из урока 03.

Важный нюанс: вкладка Code требует платной подписки (Pro, Max, Team или Enterprise). У тебя уже есть Pro из урока 02 — всё должно открыться сразу. Если при клике на Code видишь предложение оформить подписку — значит, вошёл не в тот аккаунт или подписка не активна; проверь на claude.ai/settings/billing.

Схема окна: вверху три вкладки (Chat / Cowork / Code — выбрана Code), слева файлы папки, справа диалог с агентом и предложенное изменение. Точный вид — на скриншотах, когда дойдёшь до этого шага руками.

Шаг 3. Первая сессия в Code

  1. Нажми Code. Появится выбор: Local (работа с файлами прямо на твоём компьютере — выбери её), Cloud (в облаке Anthropic) или SSH (удалённый сервер) — эти два пропускаем.
  2. Select folder → выбери ту же папку ИИ-проекты\Разбор документов, что создавал в уроке 04 (или любую другую тестовую).
  3. Выбери модель в выпадающем списке рядом с полем ввода — для черновой работы достаточно модели по умолчанию.
  4. Напиши агенту задачу, например ту же самую, что в уроке 03:

    «Создай на рабочем столе файл заметка.txt со списком дел на завтра из трёх пунктов»

  5. Приложение по умолчанию работает в режиме Manual: агент показывает, что собирается сделать (дифф — что добавится, что изменится), и ждёт твоего подтверждения кнопкой Accept, прежде чем правда тронуть файл.

Шаг 4. Пойми, чем это отличается от терминала

  • Десктоп-приложение и терминальная команда claude — один и тот же движок, просто разные окна. Настройки (CLAUDE.md, MCP-подключения, права) у них общие.
  • Можно держать открытыми оба одновременно на одном проекте — они не мешают друг другу.
  • В десктопе есть встроенный терминал (открывается сочетанием Ctrl+` внутри вкладки Code) — там точно так же работает команда claude, если вдруг захочешь вернуться к чистому терминальному виду.

Домашнее задание

Открой в приложении вкладку Code на папке из урока 04 и попроси агента навести в ней порядок: «разложи файлы по подпапкам по типам — документы, картинки, таблицы». Посмотри на дифф перед тем, как принять — сравни это ощущение с тем, как было в чистом терминале урока 03.

Заметки из практики

Урок появился по совету коллег автора курса: показывать студентам агента не только через терминал, но и через обычное окно программы — для тех, кто пугается чёрного экрана, это может быть первым шагом вместо VS Code, а не заменой ему.
