VS Code: удобное рабочее место для агента

Интерфейс расширения обновляется часто — названия кнопок сверены 20.07.2026, при прохождении ориентируйся на смысл.

Что получишь

Рабочее место, где всё в одном окне: слева файлы, в центре документ, рядом агент. Главное — ты будешь видеть каждое изменение, которое агент вносит в файлы, до того как его принять.

Кому и зачем

Терминал из урока 03 работает, но текстовый интерфейс неудобен для повседневности: не видно файлов, не видно правок. VS Code — бесплатный редактор от Microsoft, который превращает работу с агентом из «переписки вслепую» в наглядный процесс. Это не «программа для программистов» — считай его офисным приложением для работы с ИИ.

Шаги

Все сочетания клавиш в уроке — для Windows; на Mac заменяй Ctrl на Cmd (например, Cmd+Shift+X).

Шаг 1. Установи VS Code

  1. Открой code.visualstudio.com → синяя кнопка Download (сайт сам определит твою систему).
  2. Windows: запусти установщик, оставь галки по умолчанию, плюс отметь «Открывать через Code» в контекстном меню папок. Mac: распакуй скачанный архив и перетащи Visual Studio Code в папку «Программы».
  3. Запусти VS Code.

Шаг 2. Переключи на русский

  1. Нажми Ctrl+Shift+X — откроется панель расширений (Extensions).
  2. В поиске набери Russian Language Pack → Install.
  3. Справа внизу появится предложение перезапустить — соглашайся. Интерфейс станет русским.

Шаг 3. Установи расширение Claude Code

  1. Снова Ctrl+Shift+X, в поиске: Claude Code.
  2. Выбери расширение от издателя Anthropic (проверь синюю галочку верификации рядом с именем издателя!) → Install.
  3. В левой боковой панели появится иконка Claude. Нажми её.
  4. Расширение подхватит установку и авторизацию из урока 03. Если попросит войти — авторизуйся через браузер, как раньше.

Шаг 4. Освой рабочий цикл

  1. Файл → Открыть папку → выбери свою папку ИИ-проекты\Разбор документов (из урока 04). Слева увидишь дерево файлов.
  2. В панели Claude напиши задачу, например: «сделай из договора в этой папке краткую выжимку в новый файл выжимка.md».
  3. Смотри, как агент работает: какие файлы читает, что предлагает изменить. Изменения показываются диффом: красное — удаляется, зелёное — добавляется. Принять или отклонить — твоя кнопка.
  4. Созданный файл открой двойным кликом в дереве слева — читай и правь прямо здесь.

Альтернатива в том же окне: Ctrl+` (клавиша слева от единицы) открывает встроенный терминал — там работает привычная команда claude из урока 03. Панель и терминал — два входа к одному агенту, пользуйся тем, что удобнее.

Шаг 5. Три настройки для комфорта

  1. Файл → Автосохранение — включи, чтобы не терять правки.
  2. Мелкий шрифт? Ctrl и «+» — увеличение всего интерфейса.
  3. Тема: Файл → Параметры → Тема → Цветовая тема — рекомендую светлую: меньше «хакерской» эстетики, привычнее для офисных глаз.

Домашнее задание

Перенеси одно из упражнений урока 04 в VS Code: открой папку, поставь агенту ту же задачу и в этот раз прочитай дифф внимательно, прежде чем принять. Найди в изменениях хотя бы одну вещь, которую попросишь сделать иначе — и попроси.

Заметки из практики

Именно запрос автора курса «подробно нужно про подключение и настройку VS Code» породил этот урок: в большинстве материалов по Claude Code этот шаг пропускают, как «очевидный». Для непрограммиста он не очевиден — а даёт наибольший прирост удобства из всего модуля.
