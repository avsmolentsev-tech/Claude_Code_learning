Установка Claude Code на компьютер (Windows и Mac)

Факты и команды сверены с официальной документацией code.claude.com/docs 20.07.2026.

Что получишь

Работающий ИИ-агент на твоём компьютере: открываешь терминал, пишешь claude — и ставишь задачи русским языком.

Кому и зачем

Для владельца обычного ноутбука — Windows 10/11 или Mac (macOS 13+). Никаких серверов, никакого программирования — агент ставится на твой личный компьютер и работает с твоими файлами. Урок разделён на две ветки: иди по своей системе, дальше всё общее.

Шаги

Шаг 1. Пойми, что такое терминал (1 минута)

Терминал — это текстовый чат с компьютером: ты пишешь команду, компьютер отвечает. Всё.

Windows: нажми Пуск, набери PowerShell, запусти «Windows PowerShell». Появится окно со строкой вида PS C:\Users\Имя> — буквы PS в начале значат, что ты в PowerShell (это важно: команды ниже — именно для него).

Mac: нажми Cmd+Пробел (поиск Spotlight), набери Терминал, нажми Enter. Появится окно со строкой вида имя@MacBook ~ %.

Шаг 2. Установи Claude Code (основной путь)

Скопируй в терминал одну команду и нажми Enter. Установщик всё сделает сам, права администратора не нужны.

Windows (PowerShell):

irm https://claude.ai/install.ps1 | iex

Mac (Терминал):

curl -fsSL https://claude.ai/install.sh | bash

Дождись сообщения об успешной установке, затем закрой и заново открой терминал. Проверка (одинаково на обеих системах):

claude --version

Увидел номер версии (например, 2.1.211 (Claude Code)) — установка удалась. Бонус: этот способ сам обновляется в фоне, ничего поддерживать не нужно.

Шаг 3. Установи Git (рекомендуется, 5 минут)

Git расширяет возможности агента при работе с командами.

Windows: скачай с git-scm.com/download/win, при установке жми «Далее» со всеми настройками по умолчанию.

Mac: набери в Терминале git --version — если Git не установлен, macOS сама предложит поставить «Command Line Tools», соглашайся и жди. Это всё.

Шаг 4. Запусти и авторизуйся

claude

При первом запуске откроется браузер — войди в аккаунт claude.ai из урока 02 (VPN должен быть включён, если он нужен тебе для claude.ai). Вернись в терминал — агент готов.

Шаг 5. Первая проверка

Прямо в открывшемся диалоге напиши:

Создай на рабочем столе файл заметка.txt со списком дел на завтра из трёх пунктов

Агент спросит разрешение на создание файла — подтверди. Сходи на рабочий стол: файл там. Поздравляю, у тебя есть агент.

Запасной путь (если шаг 2 не сработал)

Windows:

  1. Через магазин пакетов: winget install Anthropic.ClaudeCode (после установки перезапусти PowerShell).
  2. Или через Node.js: установи Node.js версии 22 или новее с nodejs.org (в инсталлере оставь галку «Add to PATH»), перезапусти PowerShell, затем npm install -g @anthropic-ai/claude-code.

Mac:

  1. Через Homebrew (если пользуешься): brew install --cask claude-code.
  2. Или через Node.js 22+ с nodejs.org, затем npm install -g @anthropic-ai/claude-code.

Диагностика любых проблем на обеих системах: команда claude doctor — покажет, что не так с установкой.

Чек-лист

  • claude --version показывает номер версии
  • claude запускается и я авторизован
  • Агент создал файл на рабочем столе по моей просьбе

Домашнее задание

Попроси агента навести порядок в копии (!) какой-нибудь папки: «разложи файлы по подпапкам по типам — документы, картинки, таблицы». Посмотри, как он спрашивает разрешения и отчитывается о сделанном.

Заметки из практики

Прошлый поток показал: 90% проблем установки решаются простым «закрой и открой терминал заново». Прежде чем паниковать — перезапусти терминал, затем claude doctor.
