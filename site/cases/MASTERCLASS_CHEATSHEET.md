## Драматургия дня

1. **5 минут** — показать 2–3 готовых WOW DEMO.
2. **10 минут** — объяснить общий паттерн: данные → промпт → агент пишет код → запуск → проверка → улучшение.
3. **30–45 минут** — первая общая практика для всех: «Пульт бизнеса» (01) или «Цифровой продукт» (03).
4. Разделить по отделам и дать профильную практику.
5. Каждая группа показывает за 2 минуты «до → после».
6. Финал — «AI-штаб собственника» (08) как концепция соединения прототипов.

Общие правила для любой практики (из ТЗ):
- Задание НЕ выполнено, если агент только описал, «как можно сделать». Он должен создать файлы,
  запустить решение, проверить основные сценарии, исправить ошибки и показать работающую версию.
- Стек — простой и надёжный. Цель обучить результату, а не программированию.
- Базовая версия работает локально, без обязательных API-ключей.
- Интерфейс на русском, понятные кнопки, drag-and-drop для файлов, внятные пустые состояния и ошибки,
  кнопка «Начать заново».
- После сборки — smoke-test: загрузка файла, основные расчёты, кнопки, пустые данные, неправильный файл,
  повторный запуск. Результат записать в TEST_REPORT.md.
- Ничего не выдумывать: если данных нет, показать это явно. Всё, что взято из веба, — со ссылкой на источник.
