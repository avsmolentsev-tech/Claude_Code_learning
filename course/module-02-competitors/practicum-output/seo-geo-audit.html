Все данные ниже получены реальным сканированием сайтов ДЭФО, Феликс, Евроофис, Азамат-Мебель — Python-скриптом (title/meta/H1/alt/schema) и headless-браузером (скорость загрузки). Не выдумано и не «на глаз» — цифры воспроизводимы, скрипт прилагается.

Что такое СЕО и ГЕО (для небольшого бизнеса)

SEO — поисковая оптимизация

Как твой сайт понимают Яндекс и Google: правильный заголовок страницы, описание, структура (что главное — H1), картинки с подписями. Чем аккуратнее — тем чаще сайт показывают по нужным запросам.

GEO — оптимизация для ИИ-поиска

Всё чаще люди спрашивают не Яндекс, а ChatGPT/Perplexity/поиск с ИИ-ответами: «где в Казани купить офисную мебель». ГЕО — это как сделать так, чтобы именно твой сайт ИИ-ассистент процитировал в ответе: разрешить ИИ-краулерам заходить, дать структурированные факты (цены, характеристики) в понятном для машины виде.

Синтез: за счёт чего можно выиграть здесь

1

Базовая гигиена — уже преимущество

H1 на каждой странице, meta description 120–160 символов, alt на всех карточках товаров — это не «продвинутое SEO», а факт, которого не хватает двум из четырёх конкурентов прямо сейчас.

2

GEO — открытое поле

Product-схема с ценами и характеристиками + llms.txt с кратким описанием бизнеса — и при прочих равных именно наш сайт ИИ-ассистент назовёт первым на вопрос про офисную мебель в Казани. Конкуренты этим не занимались никто.

3

Скорость — не только про SEO

700 мс до первого байта у Азамат-Мебель — это ощутимая задержка для живого посетителя, не только для поисковика. Быстрый сайт — и SEO-плюс, и меньше отказов у реальных покупателей.

Инструмент: скрипт аудита (можно прогонять на любом сайте)

Одним запросом агенту («построй инструмент, который проверяет сайт по SEO и ГЕО-чек-листу») получился рабочий скрипт на Python — вот как им пользоваться:

python3 seo-geo-audit.py https://ваш-сайт.ru https://конкурент.ru

Скрипт проверяет: title/meta description (длину и наличие), H1, картинки без alt, schema.org, canonical, robots.txt (в т.ч. правила для ИИ-краулеров поимённо), llms.txt — и сохраняет результат в JSON. Скачать: seo-geo-audit.py.
