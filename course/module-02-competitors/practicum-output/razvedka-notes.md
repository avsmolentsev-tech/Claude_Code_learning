## ⚠️ Важно: первый (беглый) проход дал две неверные цифры
Первая версия разведки читала только главные страницы. Второй, глубокий проход — конкретные категории каталога («столы для персонала», «офисные кресла») — исправил две ошибки:

1. **Феликс**: главная страница создавала впечатление «цены только по запросу» (маркетинговый текст «гарантия лучшей цены» без цифр). На деле в каталоге цены открыты: кресла 4 221–16 038 ₽, столы от 4 948 ₽. Вывод: отсутствие цены на главной ≠ отсутствие цены на сайте.
2. **Азамат-Мебель**: с главной страницы показалось, что кресла стоят 20 440–42 590 ₽ (видимо, попалась витрина премиум-раздела или страница другой категории). В реальном каталоге кресел («кресла-офисные-компьютерные») — кресло оператора 4 650 ₽, кресло руководителя 8 450 ₽. Это переворачивает вывод: Азамат — самый дешёвый по креслам, а не сопоставимый по цене с premium-сегментом.

**Урок отсюда**: главная страница — это маркетинг, каталог — это данные. Для сравнения цен нужно заходить в конкретный товарный раздел, а не судить по витрине.

## SWOT-лайт по каждому

**ДЭФО** — Сильное: широта каталога и диапазон цен закрывает любой чек. Слабое: без явного УТП — «всё для всех» может размывать позиционирование. Для нас: конкурировать по ассортименту с ДЭФО бессмысленно — искать нишу внутри диапазона.

**Феликс** — Сильное: доверие через масштаб (60+ салонов, известные клиенты) и заявленную гарантию 10 лет. Слабое: маркетинг обещает больше, чем показывает при поверхностном взгляде («цены по запросу» на главной отпугивает часть аудитории, которая не пошла в каталог). Для нас: явно показывать цены — простое конкурентное преимущество против их же маркетинговой ошибки.

**Евроофис** — Сильное: скорость (доставка за 1 день из наличия) и возраст бренda как аргумент доверия. Слабое: цены на входе выше конкурентов — уязвимы по самому чувствительному сегменту (маленький бизнес, экономящий на столах). Для нас: демпинговать именно во входной категории столов.

**Азамат-Мебель** — Сильное: реально самый дешёвый вариант, прозрачные цены. Слабое: почти нет сервисных обещаний (нет дизайн-проекта, нет упоминания тендеров) — воспринимается как «магазин», а не «партнёр для офиса». Для нас: если целимся не в демпинг, а в средний+ чек — Азамат не конкурент вовсе, а ценовой якорь снизу.
