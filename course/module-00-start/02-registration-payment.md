Модуль: M0. Старт · Уровень: Новичок · Время: ~60 мин (+ ожидание SMS)

## Шаги

### Шаг 1. Установи VPN
VPN — это программа, которая меняет твоё виртуальное «местоположение» в интернете. Claude и многие другие AI-сервисы заблокированы для пользователей из России; VPN делает так, что сервис видит тебя как пользователя другой страны — и пускает. **Без VPN ничего из курса работать не будет.** Он нужен и на компьютере (для Claude Code), и на телефоне.

Полученный файл `.conf` — это «ключ» для подключения. Открой его в приложении **AmneziaWG**:
- Windows: скачай [AmneziaWG для Windows](https://github.com/amnezia-vpn/amneziawg-windows-client/releases) (файл `.exe`/`.msi` в блоке Assets последнего релиза) → установи → «Добавить туннель» → «Импортировать туннель(и) из файла» → выбери конфиг → «Подключить».
- macOS: App Store → найди AmneziaWG → установи → «Добавить туннель» → «Импорт из файла» → разреши добавление VPN-конфигураций (пароль от Mac) → включи туннель.

**Главное правило:** VPN должен быть включён на ВСЕХ шагах — и при создании почты, и при регистрации на claude.ai, и потом при любой работе с Claude. Половина «непонятных ошибок» — это просто выключившийся VPN.

### Шаг 2. Купи номера и заведи почту
Для регистрации в Claude нужны два компонента:
- **нероссийская почта** — подойдёт Gmail (@mail.ru и @yandex.ru не принимаются);
- **иностранный номер телефона** — для SMS-верификации.

Оба номера (для Gmail и для Claude) можно купить на одном сервисе — [5sim.net](https://5sim.net). Номера одноразовые: нужны только чтобы получить SMS с кодом, после верификации они не понадобятся — доступ держится на почте.

**2.1. Пополни баланс на 5sim.net.** Зарегистрируйся, пополни на **100 ₽** (хватит на два номера) — «Банковская карта» или «СБП», российские карты принимаются.

**2.2. Какую страну выбирать?** Лучше всего — **Латвия**: та же страна, где стоит наш VPN-сервер. Тогда для Google и Claude всё выглядит естественно: ты «находишься» в Латвии, и номер латвийский — меньше проверок и отказов. Если латвийских нет в наличии — другая европейская (Великобритания, Швеция, Эстония).

**2.3. Создай Gmail** (если уже есть — пропусти). Открой [accounts.google.com/signup](https://accounts.google.com/signup), заполни имя и адрес. Когда Google попросит телефон — купи на 5sim.net номер: в поиске услуг введи «Google», страна — Латвия. Вставь номер в форму Google, вернись на 5sim.net, дождись SMS (10–30 сек), введи код — почта создана. Запиши пароль: потеряешь почту — потеряешь и доступ к Claude.

> Если Google не принимает номер или пишет «Подозрительная активность» — попробуй: (а) временно отключить VPN, (б) режим инкогнито, (в) свой существующий Gmail, если есть.

**2.4. Купи номер для Claude.** На 5sim.net в поиске услуг введи «Claude» или «Anthropic», страна — Латвия (или другая европейская). Купи и **не закрывай страницу** — сюда придёт SMS. Если SMS нет за 60 секунд — жми «Отменить» (деньги вернутся на баланс) и бери номер другой страны. Не все номера срабатывают с первого раза — это нормально, 2–3 попытки.

### Шаг 3. Зарегистрируйся на claude.ai
1. Включи VPN, открой [claude.ai](https://claude.ai) → **Sign up** → введи Gmail из шага 2. (Если видишь только «Log in» — нажми, внизу формы будет ссылка «Sign up». Сайт не грузится — проверь VPN на 2ip.ru.)
2. Когда попросят телефон — скопируй номер с 5sim.net **полностью, с кодом страны** (начинается с «+»). Если Claude просит выбрать страну — та же, что при покупке номера.
3. Вернись во вкладку 5sim.net, дождись SMS (обычно 10–30 секунд), введи код на claude.ai. Готово — ты в системе.

## Типичные ошибки
| Симптом | Причина | Решение |
|---|---|---|
| claude.ai не открывается / странные ошибки | VPN выключен или отвалился | Проверь 2ip.ru; переподключи туннель в AmneziaWG |
| Конфиг не импортируется в приложение | Установлен AmneziaVPN вместо AmneziaWG | Поставь именно AmneziaWG — конфиги работают только в нём |
| VPN не подключается дома, а с телефона работает | Роутер/провайдер режет VPN-протоколы | Раздай интернет с телефона; напиши нам — дадим другой конфиг |
| SMS не приходит | Номер «выгорел» — уже использован для Claude | Жми «Отменить» на 5sim (деньги вернутся), бери другую страну: Великобритания, Швеция, Эстония |
| Платёж отклонён | Карта/посредник под блокировкой или VPN выключен | Включи VPN (для «Плати по Миру» — попробуй Великобританию); смени сервис из списка |
| Аккаунт просит повторную верификацию | Частая смена VPN-локаций | Заходи из одной «страны» VPN, не прыгай по локациям |
| Забанили аккаунт после регистрации | Совпадение факторов риска (номер+VPN) | Написать в поддержку; при повторе — новый аккаунт на другую почту и номер другой страны |
