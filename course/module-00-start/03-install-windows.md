# Установка Claude Code на компьютер (Windows)

Модуль: M0. Старт · Уровень: Новичок · Время: ~30 мин

Факты и команды сверены с официальной документацией code.claude.com/docs 20.07.2026. Перед публикацией скриншотов — сверить ещё раз.

## Что получишь
Работающий ИИ-агент на твоём компьютере: открываешь PowerShell, пишешь `claude` — и ставишь задачи русским языком.

## Кому и зачем
Для владельца обычного ноутбука на Windows 10/11. Никаких серверов, никакого программирования — агент ставится на твой личный компьютер и работает с твоими файлами.

## Шаги

### Шаг 1. Пойми, что такое терминал (1 минута)
Терминал — это текстовый чат с компьютером: ты пишешь команду, компьютер отвечает. Всё.

Открой его: нажми **Пуск**, набери `PowerShell`, запусти «Windows PowerShell». Появится синее/чёрное окно со строкой вида `PS C:\Users\Имя>` — буквы `PS` в начале значат, что ты в PowerShell (это важно: команды ниже — именно для него).

### Шаг 2. Установи Claude Code (основной путь)
Скопируй в PowerShell одну команду и нажми Enter:

```powershell
irm https://claude.ai/install.ps1 | iex
```

Установщик всё сделает сам (права администратора не нужны). Дождись сообщения об успешной установке, затем **закрой и заново открой PowerShell**.

Проверка:

```powershell
claude --version
```

Увидел номер версии (например, `2.1.211 (Claude Code)`) — установка удалась. Бонус: этот способ сам обновляется в фоне, ничего поддерживать не нужно.

### Шаг 3. Поставь Git (рекомендуется, 5 минут)
Git расширяет возможности агента при работе с командами. Скачай с `git-scm.com/download/win`, при установке жми «Далее» со всеми настройками по умолчанию.

### Шаг 4. Запусти и авторизуйся
В PowerShell набери:

```powershell
claude
```

При первом запуске откроется браузер — войди в аккаунт claude.ai из урока 02 (VPN должен быть включён, если он нужен тебе для claude.ai). Вернись в терминал — агент готов.

### Шаг 5. Первая проверка
Прямо в открывшемся диалоге напиши:

> Создай на рабочем столе файл заметка.txt со списком дел на завтра из трёх пунктов

Агент спросит разрешение на создание файла — подтверди. Сходи на рабочий стол: файл там. Поздравляю, у тебя есть агент.

### Запасной путь (если шаг 2 не сработал)
1. Попробуй через магазин пакетов Windows: `winget install Anthropic.ClaudeCode` (после установки перезапусти PowerShell).
2. Или через Node.js: установи Node.js **версии 22 или новее** с nodejs.org (в инсталлере оставь галку «Add to PATH»), перезапусти PowerShell, затем `npm install -g @anthropic-ai/claude-code`.
3. Диагностика любых проблем: команда `claude doctor` — покажет, что не так с установкой.

## Типичные ошибки
| Симптом | Причина | Решение |
|---|---|---|
| `irm не распознан...` | Ты в CMD, а не в PowerShell | В начале строки должно быть `PS`. Открой именно Windows PowerShell |
| `claude не распознан` после установки | PowerShell кеширует пути | Полностью закрой и заново открой PowerShell; не помогло — перезагрузи компьютер |
| «Запуск скриптов отключён в этой системе» | Политика безопасности PowerShell | PowerShell от имени администратора → `Set-ExecutionPolicy RemoteSigned -Scope CurrentUser` → `Y` → перезапустить PowerShell |
| Установка зависает или «Access Denied» | Антивирус блокирует | Временно отключи антивирус на время установки, потом включи и добавь папку `%USERPROFILE%\.local\share\claude` в исключения |
| `npm не распознан` (запасной путь) | Node.js без галки PATH | Переустанови Node.js с nodejs.org, отметь «Add to PATH», перезагрузись |
| Не открывается окно авторизации | claude.ai недоступен из сети | Проверь: открывается ли claude.ai в браузере. Нет — включи/смени VPN. Скопируй ссылку из терминала в браузер вручную |
| Агент отвечает очень медленно / останавливается | Исчерпан лимит подписки | Проверь план на claude.ai (урок 02); лимиты Pro восстанавливаются через несколько часов |
| Просит Python для какой-то задачи | Python не установлен | Microsoft Store → «Python 3.12» → установить → перезапустить PowerShell |

## Домашнее задание
Попроси агента навести порядок в копии (!) какой-нибудь папки: «разложи файлы по подпапкам по типам — документы, картинки, таблицы». Посмотри, как он спрашивает разрешения и отчитывается о сделанном.

## Заметки из практики
Прошлый поток показал: 90% проблем установки решаются простым «закрой и открой PowerShell заново». Прежде чем паниковать — перезапусти терминал, затем `claude doctor`.
