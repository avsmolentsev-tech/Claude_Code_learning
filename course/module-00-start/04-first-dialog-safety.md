# Первый диалог: разрешения и гигиена данных

Модуль: M0. Старт · Уровень: Новичок · Время: ~30 мин

## Что получишь
Три выполненных упражнения с агентом, понимание системы разрешений и главное правило работы с данными клиентов — чтобы пользоваться ИИ смело, но не подставить бизнес.

## Кому и зачем
Для каждого, кто дошёл до работающего агента (урок 03). Здесь закладываются привычки, которые отличают уверенного пользователя от того, кто «боится что-то сломать» — или наоборот, ломает.

## Шаги

### Шаг 1. Заведи рабочую папку
Агент видит файлы той папки, в которой запущен. Создай себе базу:

1. Создай папку `ИИ-проекты` (Windows: `C:\ИИ-проекты\`; Mac: в домашней папке, в терминале это `~/ИИ-проекты`) и в ней подпапку под первую задачу, например `Разбор документов`.
2. В терминале перейди в неё: Windows — `cd C:\ИИ-проекты\Разбор документов`, Mac — `cd ~/ИИ-проекты/Разбор документов`
3. Запусти `claude`.

Теперь агент работает именно здесь — не гуляет по всему компьютеру.

### Шаг 2. Разберись с разрешениями
Перед действием (создать файл, запустить команду) агент **спрашивает разрешение** — ты увидишь запрос с вариантами «разрешить один раз / разрешить всегда / отказать». Это твой контроль над агентом.

Режимы — от «спрашивать про каждый шаг» до «делай всё сам». Правило курса: **пока учишься — пусть спрашивает**. Разрешение «всегда» давай только действиям, которые понимаешь (например, «создавать файлы в этой папке»).

### Шаг 3. Три упражнения
Выполни по очереди (для первого — сначала сделай копию папки!):

1. **Порядок в загрузках**: скопируй папку «Загрузки» в рабочую папку и попроси: «разложи файлы по подпапкам по типам: документы, таблицы, картинки, остальное».
2. **Выжимка из договора**: положи в папку любой договор (PDF или Word) и попроси: «прочитай договор и выпиши стороны, суммы, сроки и штрафные санкции списком».
3. **Таблица из скриншотов**: положи 3–5 скриншотов чеков или платёжек и попроси: «собери из этих картинок таблицу расходов: дата, получатель, сумма».

После каждого — проверь результат. Заметь: агент отчитывается, что сделал, и его можно попросить переделать.

### Шаг 4. Выучи правило гигиены данных
Облачный агент отправляет содержимое файлов на серверы за рубежом. По закону 152-ФЗ «О персональных данных» ты как бизнес отвечаешь за данные своих клиентов. Отсюда правило:

> **Персональные данные клиентов (ФИО + телефон + почта + адреса) в облачный ИИ как есть не загружаем.**

Что делать вместо:
- **Обезличивай**: перед загрузкой выгрузки удали колонки с ФИО/телефонами или замени на «Клиент 1», «Клиент 2» (агент сам напишет тебе скрипт обезличивания — попроси!);
- **Агрегируй**: для аналитики чаще всего хватает сумм по месяцам/категориям без единой фамилии;
- Внутренние документы без чужих персональных данных (свои прайсы, договоры-шаблоны, отчёты) — можно спокойно.

Полный практический разбор (включая российские модели для работы с персональными данными) — в модуле М6.

## Типичные ошибки
| Симптом | Причина | Решение |
|---|---|---|
| Агент «не видит» нужный файл | Запущен в другой папке | Выйди (`/exit` или Ctrl+C), перейди `cd` в нужную папку, запусти заново |
| Разрешил «всегда» что-то лишнее | Жал не глядя | Разрешения можно сбросить в настройках проекта — спроси у самого агента: «покажи и сбрось мои разрешения» |
| Загрузил клиентскую базу с ФИО | Привычка «скорее к делу» | Впредь — обезличить. Попроси агента: «напиши скрипт, который заменяет ФИО и телефоны в CSV на Клиент N» |
| Агент сделал «не то» | Размытая формулировка | Формулируй результат, а не процесс: не «поработай с файлами», а «разложи по подпапкам по типам» |

## Домашнее задание
Придумай и выполни три своих запроса к агенту на реальных файлах твоего бизнеса (обезличенных!). Запиши: что получилось с первого раза, что пришлось переформулировать. Эти записи пригодятся — по ним ты увидишь, как растёт твой навык постановки задач.

## Заметки из практики
Самый частый вопрос новичка: «а можно ли ему доверять мои файлы?» Ответ из практики: агент не делает ничего без разрешения — страх уходит после первых трёх упражнений, когда видишь каждый его шаг. Контроль у тебя.
