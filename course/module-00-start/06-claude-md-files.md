# CLAUDE.md и файлы, которые надо настроить сразу

Модуль: M0. Старт · Уровень: Новичок · Время: ~30 мин

## Что получишь
«Должностную инструкцию» для твоего агента: он начнёт отвечать по-русски, считать в рублях и соблюдать твои правила — без напоминаний в каждом диалоге. Плюс правильную структуру папок на старте.

## Кому и зачем
Агент — как новый сотрудник: толковый, но о твоём бизнесе не знает ничего и каждое утро приходит «с чистого листа». CLAUDE.md — файл с инструкциями, который агент перечитывает при каждом запуске. Один раз написал — работает всегда. Это самый недооценённый час настройки из всего курса.

## Шаги

### Шаг 1. Пойми два уровня инструкций
- **Глобальный** — «про тебя», действует во всех папках и проектах. Windows: `C:\Users\<твоё имя>\.claude\CLAUDE.md`; Mac: `~/.claude/CLAUDE.md` (папка скрытая — в Finder покажи скрытые файлы сочетанием Cmd+Shift+точка).
- **Проектный** `CLAUDE.md` в папке задачи — «про эту работу». Действует только там.

Агент читает оба: сначала твой общий, потом проектный.

### Шаг 2. Напиши глобальный CLAUDE.md
Открой в VS Code папку `.claude` из своей домашней папки (если файла CLAUDE.md нет — создай). Лайфхак для обеих систем: можно просто попросить агента — «создай мне глобальный CLAUDE.md с таким содержимым…». Возьми за основу и перепиши под себя:

```markdown
# Обо мне
Я — [имя], владелец [бизнес: например, сети магазинов автозапчастей в Казани].
Не программист: объясняй по-простому, без жаргона.

# Правила
- Общайся по-русски.
- Суммы в рублях, формат: 1 234 567 ₽.
- Даты в формате ДД.ММ.ГГГГ.
- Перед удалением файлов или отправкой чего-либо в интернет — спрашивай.
- Деловые документы пиши без канцелярита, коротко.
```

Сохрани. Проверь: запусти агента в любой папке и спроси «сколько будет 1500 долларов по курсу 90?» — ответ должен прийти по-русски и в формате с ₽.

### Шаг 3. Заведи проектный CLAUDE.md
1. Открой в VS Code рабочую папку, например `ИИ-проекты\Отчёты по продажам`.
2. В панели агента набери команду `/init` — агент осмотрит папку и создаст черновик CLAUDE.md.
3. Допиши руками главное, чего агент не знает:

```markdown
# Что в этой папке
Выгрузки из 1С по продажам. Колонки: дата, контрагент, номенклатура, сумма, менеджер.
Файлы приходят раз в неделю, имя вида sales_2026-07.xlsx.

# Правила проекта
- Готовые отчёты складывай в подпапку reports/.
- В отчётах не показывай наценку — только выручку.
- Черновики удаляй после подтверждения результата.
```

### Шаг 4. Настрой стартовую структуру папок
Минимальный набор, который стоит завести сегодня:

```
ИИ-проекты\              (Windows: C:\ИИ-проекты\, Mac: ~/ИИ-проекты/)
  Отчёты по продажам\   ← CLAUDE.md + выгрузки
  Документы\            ← CLAUDE.md + договоры, шаблоны
  Контент\              ← CLAUDE.md + посты, тексты
```

Правило: **одна задача — одна папка — свой CLAUDE.md**. Агент в папке «Контент» не должен спотыкаться об выгрузки из 1С.

### Шаг 5. Узнай, что живёт рядом (пока без настройки)
В папке проекта агент может создать служебную папку `.claude` — внутри неё:
- `settings.json` — тонкая настройка разрешений («это можно без вопросов») — разберём в М9;
- свои команды и скилы — научимся делать в М3.

Сейчас просто знай, что они есть — трогать не нужно.

## Чек-лист
- [ ] Глобальный CLAUDE.md написан, агент отвечает по-русски и в рублях в любой папке
- [ ] В одной рабочей папке есть проектный CLAUDE.md (через `/init` + правки руками)
- [ ] Структура `ИИ-проекты` с папками по задачам создана

## Типичные ошибки
| Симптом | Причина | Решение |
|---|---|---|
| Агент игнорирует часть инструкций | CLAUDE.md — простыня на 3 страницы | Сокращай. Короткие списки работают, эссе — нет |
| Агент «путается в показаниях» | Противоречивые правила (в глобальном одно, в проектном другое) | Проверь оба файла, убери конфликт: проектный уточняет глобальный, а не спорит с ним |
| Вписал в CLAUDE.md весь прайс на 500 позиций | Перепутал инструкции с данными | CLAUDE.md — правила. Данные (прайсы, справочники) — отдельными файлами в папке, агент их найдёт |
| Создал CLAUDE.md, а агент не заметил | Файл создан после запуска агента | Перезапусти диалог — инструкции читаются на старте |

## Домашнее задание
Напиши глобальный CLAUDE.md про свой бизнес и проектный — для одной реальной папки. Тест: задай агенту вопрос, где инструкции должны проявиться (валюта, язык, тон), и убедись, что они работают. Потом неделю дописывай по одному правилу каждый раз, когда агент сделал «не так, как ты привык».

## Заметки из практики
Вопрос автора курса, породивший урок: «про CLAUDE.md — какие там файлы надо сразу настроить?» Ответ уместился в шаг 4: на старте достаточно глобального CLAUDE.md и папок с проектными. Всё остальное (настройки, скилы, хуки) — по мере роста, в свои модули.
