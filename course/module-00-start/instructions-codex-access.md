# Как зайти в Codex

Инструкция · дополнение к М0 · Уровень: Новичок · Время: ~30 мин (если М0-02 уже пройден)

Страница на сайте: `site/codex-access.html`

## Что получишь
Рабочий доступ к Codex — агенту от OpenAI, который живёт в терминале и делает работу на твоём компьютере, как Claude Code.

## Кому и зачем
Курс построен на Claude. Codex нужен как **второй** агент, а не замена:
- **кончились лимиты** — доделать работу сегодня, а не завтра;
- **нужно второе мнение** — агент третий раз чинит одно и то же и ходит по кругу;
- **уже есть подписка ChatGPT** — Codex в неё включён.

Если только начинаешь — второй агент не нужен, доведи до результата один.

## Что понадобится
Те же четыре барьера, что в М0-02: VPN, нероссийская почта, иностранный номер, зарубежная карта. **Если М0-02 пройден — три из четырёх уже есть**, докупить нужен только новый одноразовый номер.

## Шаги

### Шаг 1. Включи VPN
OpenAI не работает из России: ни регистрация, ни оплата, ни вход в Codex. Настройка — М0-02, шаг 1 (AmneziaWG, проверка на 2ip.ru). VPN нужен постоянно, не только при регистрации.

Практическое следствие: вход в Codex идёт через браузер, и браузер с терминалом должны в этот момент видеть интернет через один VPN. Половина «зависших логинов» — отвалившийся туннель.

### Шаг 2. Заведи аккаунт ChatGPT
1. С включённым VPN открой [chatgpt.com](https://chatgpt.com) → **Sign up**. Почта — тот же Gmail, что для Claude.
2. Номер для SMS — на [5sim.net](https://5sim.net): услуга **OpenAI** или **ChatGPT**, страна — та же, что у VPN-сервера (в курсе — Латвия).
3. Вставь номер с кодом страны, дождись SMS (10–30 сек), введи код.

Нет SMS за минуту — «Отменить» (деньги вернутся) и брать номер другой европейской страны. 2–3 попытки — норма.

### Шаг 3. Оформи подписку
**На бесплатном плане Codex не работает.** Нужен Plus, Pro, Business, Edu или Enterprise.
- **Plus — $20/мес** — рабочий минимум для курса.
- **Pro** — заметно дороже, только при ежедневной интенсивной работе.
- **Business** — командный, от двух рабочих мест.

Цены на август 2026, проверяй на [openai.com/chatgpt/pricing](https://openai.com/chatgpt/pricing/) — OpenAI меняет тарифы часто.

Российские карты не принимаются. Способы оплаты — те же, что в М0-02, шаг 4 (ArpoZan, «Плати по Миру», MIG Pay, WantToPay, карта иностранного банка). VPN при оплате включён.

### Шаг 4. Установи Codex
**Windows** (PowerShell):
```
powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"
```

**macOS и Linux**:
```
curl -fsSL https://chatgpt.com/codex/install.sh | sh
```

Та же команда обновляет Codex — запускай раз в пару недель.

Альтернативы: `npm install -g @openai/codex` (Node.js уже стоит, если ставил Claude Code по М0-03) или `brew install --cask codex` на Mac.

⚠️ **Главная ловушка.** В npm есть пакет с коротким именем `codex` — **он не от OpenAI**. Ставится без ошибок и ничего не делает. Нужен именно `@openai/codex`.

**Про Windows и WSL.** WSL не нужен: нативная установка в PowerShell работает, агент использует встроенную песочницу Windows (блокирует запись за пределами рабочей папки и выход в сеть без разрешения). WSL нужен, только если сам проект завязан на линуксовые инструменты. Грабля: в служебной документации репозитория висит устаревшая строка «Windows 11 via WSL2» — ориентируйся на официальный установщик.

### Шаг 5. Войди в аккаунт
1. Перезапусти терминал.
2. Перейди в рабочую папку, набери `codex`.
3. Выбери **Sign in with ChatGPT**.
4. В открывшемся браузере войди и подтверди доступ.
5. Вернись в терминал — вход завершится сам, ключи сохранятся.

Как устроено внутри: Codex поднимает локальный сервер на порту **1455** и ждёт подтверждения от браузера. Отсюда два сбоя — браузер ушёл мимо VPN либо порт занят.

Команды: `codex login` (войти заново), `codex login status` (под каким аккаунтом работаю), `codex logout` (выйти).

**Если браузера нет** (сервер, SSH): `codex login --device-auth` — режим в бете, показывает код для ввода в браузере на другом устройстве. Либо проброс порта: `ssh -L 1455:localhost:1455 …`

**Вход по API-ключу** — отдельный способ для разработчиков: оплата по факту токенов, а не подпиской. Для курса не нужен и почти всегда дороже.

### Шаг 6. Проверь результат
1. `codex login status` — показывает аккаунт и план.
2. Запусти `codex` в рабочей папке: «Расскажи, что лежит в этой папке».
3. Служебные команды внутри: `/status`, `/model`, `/permissions`, `/review`.

Проверяй содержимым, а не ощущением «вроде запустилось»: пусть агент назовёт реальные имена файлов.

## Где ещё живёт Codex
Аккаунт и подписка одни и те же:
- **Расширение для редактора** — VS Code, Cursor, Windsurf: [developers.openai.com/codex/ide](https://developers.openai.com/codex/ide). Привычный вариант, если работаешь в VS Code по М0-06.
- **Десктоп-приложение** — команда `codex app`. Аналог вкладки Code в приложении Claude (М0-05).
- **Codex Web** — облачный агент на [chatgpt.com/codex](https://chatgpt.com/codex): работает на серверах OpenAI, локальных файлов не видит.

## Чем отличается от Claude Code
Логика одинаковая: задача обычным языком → агент читает файлы, делает работу, спрашивает разрешения. Отличия:
- **Файл настроек — `AGENTS.md`**, а не `CLAUDE.md`. Смысл тот же (М0-07). Создаётся командой `/init`.
- **Своя система разрешений и песочницы** — через `/permissions`. Правила гигиены из М0-04 действуют без изменений.

Какой агент «лучше» — вопрос без общего ответа, они меняются местами от версии к версии. Практика: держать оба и сравнивать на своих задачах.

## Типичные ошибки
| Симптом | Причина | Решение |
|---|---|---|
| `codex: command not found` | Терминал не перезапущен | Закрой и открой заново; не помогло — переустанови официальным установщиком |
| Установилось, но команда ничего не делает | Поставлен чужой пакет `codex` из npm | `npm uninstall -g codex`, затем `npm install -g @openai/codex` |
| «Требуется платный план» | Аккаунт на бесплатном тарифе | Оформи Plus — на Free Codex не работает |
| Браузер открылся, терминал ждёт вечно | VPN отвалился либо порт 1455 занят | Проверь 2ip.ru, закрой лишние программы, повтори `codex login` |
| Скрипт не запускается на Windows | Политика запуска скриптов PowerShell | Копируй команду целиком — `-ExecutionPolicy ByPass` в ней уже есть |
| Сайт не открывается, ошибки при оплате | VPN выключен или локация под блокировкой | Переподключи туннель, при оплате попробуй другую страну |
| Нет браузера (сервер, SSH) | OAuth-вход требует браузера | `codex login --device-auth` либо `ssh -L 1455:localhost:1455` |

## Гигиена и данные
- **`~/.codex/auth.json` — это пароль.** В нём ключи доступа к аккаунту. Не копировать в общие папки, не отправлять в мессенджеры, не класть в облако. Передаёшь компьютер — сначала `codex logout`.
- **OpenAI — такой же иностранный сервис, как Anthropic.** Правила из М6-03 про 152-ФЗ действуют один в один: персональные данные клиентов-физлиц не отправляем, работаем с обезличенными копиями (инструмент из М5-02).
- **Два агента — две подписки и два счёта.** Заводи Codex, когда есть причина из списка выше, а не «на всякий случай».
