# Этап 1 курса «ИИ-агенты для предпринимателей»: инфраструктура + Модуль 0

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Запустить конвейер курса: структура папок, шаблоны, outline, четыре урока Модуля 0 (установка на личный компьютер) и первый контент-пакет.

**Architecture:** Контентный репозиторий на Markdown: `course/` (уроки по шаблону), `content/` (пакеты для площадок), `templates/`, `journal/`. Материалы М0 адаптируются из прошлого курса `/root/projects/Курс по Claude` (дорожка VDS исключается). Спека: `docs/superpowers/specs/2026-07-20-ai-course-design.md`.

**Tech Stack:** Markdown, git; дизайн-гайд из прошлого курса как стандарт для будущих HTML/PDF-материалов.

## Global Constraints

- Язык всех материалов: русский; обращение к ученику на «ты».
- Тон: «я сам прошёл этот путь», честные затыки, без инфоцыганского пафоса.
- Платформа ученика: Windows 10/11, установка только на личный компьютер — **никаких VDS/серверов**.
- Основная площадка контента: Telegram; VK — адаптация; Reels/YouTube — только сценарии.
- Яндекс-инструменты в материалах: только Диск, YandexGPT/AI Studio (в контексте 152-ФЗ), Вордстат.
- Визуальный стандарт (для будущих HTML/PDF): `/root/projects/Курс по Claude/materials/DESIGN.md` — белый фон, текст #171717, акцент #10A37F, Inter, радиусы ≤12px.
- Проверка каждого урока: соответствие шаблону `templates/lesson.md` (все секции присутствуют, есть чек-лист и домашка).
- Коммит после каждой задачи, сообщения на русском.
