# Дизайн: курс «ИИ-агенты для предпринимателей» (рабочее название)

Дата: 2026-07-20. Статус: утверждено устно, ожидает финального ревью.

## Замысел

Александр осваивает Claude Code / Claude Cowork для собственных бизнес-задач и параллельно превращает своё обучение в курс для других предпринимателей. Бизнес-модель курса (платный продукт / воронка к услугам / сообщество) сознательно не выбрана — решение будет принято по реакции аудитории в процессе публикаций.

**Позиционирование**: 90% курсов на рынке — промпты для ChatGPT и конструкторы чат-ботов. Наша ниша — **агенты, которые реально выполняют работу** (документы, аналитика, CRM, 1С, автоматизация). Системных русскоязычных курсов по Claude Code/Cowork для бизнеса почти нет; Cowork вышел в январе 2026 — тема на взлёте.

## Аудитория

Широкая: все предприниматели, от новичков до продвинутых. Риск размытия фокуса снимается трёхуровневой структурой (Новичок → Практик → Продвинутый). Тон материалов — «я сам прошёл этот путь»: честные затыки автора включаются в уроки.

## Подход: «Курс растёт из обучения»

Черновой скелет курса фиксируется сразу; детализация — только по мере того, как Александр сам проходит тему на реальных задачах своего бизнеса. Каждый практикум даёт два артефакта: урок в базу курса и контент-пакет для соцсетей (learn in public). Отвергнутые альтернативы: «сначала полная программа» (переделки, риск застрять в планировании) и «контент-первый» (хаотичная база, курс дольше).

## Скелет курса

### Уровень «Новичок»
- **М0. Старт** — агентский ИИ как тренд; установка; доступ и оплата из РФ; система разрешений и безопасность; базовая гигиена данных (152-ФЗ лайт).
- **М1. Документы и таблицы** — анализ Excel-выгрузок, отчёты Word, PDF, презентации. Быстрый «вау-результат».
- **М2. Анализ конкурентов и рынка** — веб-поиск, сбор данных с сайтов, структурированный отчёт; немного Вордстата (анализ спроса).

### Уровень «Практик»
- **М3. Контент для соцсетей** — контент-план, посты под площадки, генерация изображений; здесь же первый собственный скил ученика.
- **М4. Дашборды и бизнес-аналитика** — из выгрузки в интерактивный дашборд, регулярные отчёты.
- **М5. Вайб-кодинг для бизнеса** — лендинг, калькулятор, мини-инструмент без программистов.

### Уровень «Продвинутый»
- **М6. Подключение сервисов (MCP)** — Google Drive / Яндекс.Диск, CRM, 1С, базы данных. Урок «ИИ и 152-ФЗ на практике»: клиентские данные — в российскую модель (YandexGPT / AI Studio, минимально), остальное — в Claude. Реальный кейс: CRM «Атланты».
- **М7. Автоматизация** — задачи по расписанию, субагенты; урок «n8n vs Claude-агенты: что когда»; нейро-сотрудник для клиентов (Telegram-бот на заявках + CRM).
- **М8. Видеопроизводство на автомате** — склейки (ffmpeg), субтитры (Whisper), озвучка/аватары (HeyGen и аналоги). Мета-кейс: пайплайн производит видео для этого же курса.
- **М9. Профи-приёмы и экосистема** — экономия токенов и контекста; где искать готовые скилы (маркетплейсы, плагины, superpowers); Hugging Face и open-source; российские модели обзорно (одной строкой: Алиса AI, GigaChat и др.).
- **М10 (опционально, позже)** — внедрение в команду.

Яндекс-инструменты сознательно сведены к минимуму: Диск, YandexGPT/AI Studio (только в контексте 152-ФЗ), Вордстат. Без отдельных уроков по DataLens, Шедевруму, Метрике, Алисе.

```
docs/superpowers/specs/ — дизайн-документы
```

## Рабочий ритм занятия

1. **Практикум** — реальная бизнес-задача Алексея по теме текущего модуля.
2. **Урок** — оформление по шаблону: цель → кому подходит → шаги со скриншотами → чек-лист → типичные ошибки → домашнее задание.
3. **Контент-пакет** — длинный пост Telegram, адаптация VK, сценарий Reels (30–60 сек), план скринкаста YouTube. Тексты публикуются сразу; видео — по возможности (сценарии готовятся всегда).
4. **Журнал** — реальные вопросы и затыки записываются дословно.

В М3 шаги 2–3 оформляются в собственный скил `/урок` (одной командой в конце занятия) — одновременно удобство и живой учебный пример.

## Площадки публикаций

Telegram (основная, длинные посты), VK (адаптация), Reels и YouTube (сценарии всегда, съёмка по силам). Все тексты генерируются из одного урока.

## Критерии успеха (первые ~2 месяца)

1. Александр самостоятельно выполняет «домашку» каждого пройденного модуля.
2. Каждый практикум даёт минимум один урок в `course/`.
3. Telegram-канал ведётся регулярно.
4. Накоплено достаточно материала и реакции аудитории для осознанного выбора бизнес-модели курса.

## Первый шаг

Создать структуру папок и шаблоны, зафиксировать `outline.md`, пройти М0 + начало М1 на реальном документе/выгрузке Алексея. Конвейер (урок + контент-пакет) запускается с первого же занятия.

## Повторное использование прошлого курса

Из `/root/projects/Курс по Claude` (однодневный воркшоп, июнь 2026) переиспользуем:

- **Инструкция по установке** (из спеки воркшопа) — основа М0. Изменение: только установка на личный компьютер (Windows), дорожка с VDS-сервером исключается.
- **`materials/02-install/troubleshooting.md`** — раздел «типичные ошибки» урока М0 (без проблем 8–9 про VDS).
- **`materials/DESIGN.md`** — визуальный стандарт всех материалов нового курса (минимализм, белый фон, акцент #10A37F, Inter, стили Chart.js).
- Точечно: демо-материалы (CSV с заказами, промпты секций) — как заготовки для М1, М4 и урока «нейро-сотрудник».
